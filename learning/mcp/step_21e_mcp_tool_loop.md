## 学习目标

复用原生循环思想。对照具体输入解释每个参数从哪里来、返回值交给谁以及失败发生在哪一层。

先阅读 [MCP错误分层](step_21d_error_layers.md)。 使用环境：.venv-mcp。所有Python命令在仓库根目录运行；安装见 [运行说明](../../docs/setup.md)。

## 文件职责

- [step_21e_mcp_tool_loop.py](step_21e_mcp_tool_loop.py)：本课学习代码。
- [独立依赖](requirements.txt)：使用MCP环境安装，不混入框架环境。

## 具体输入与执行过程

```text
模拟模型
→ Client调用真实MCP工具
→ tool消息
→ 模拟模型修正/回答
```

先找到入口，再标出关键函数的参数与返回点。学习脚本是分步实现；`app`中的整合版可能同时支持演示与数据库后端，观察时记下当前配置，避免混用结果。

## 运行与预期结果

**访问范围：本地演示，不请求外部模型。**

```console
python -m learning.mcp.step_21e_mcp_tool_loop
```

应观察到：本地演示成功、未找到、参数纠正和调用上限。





## 常见错误

- 导入失败：确认位于仓库根目录，并使用本课对应的独立环境。
- 运行结果与预期不同：先检查后端配置、前置服务及当前代码版本，再判断是否属于模型行为差异。
- 应用的run_tool_loop控制；MCP只负责工具发现与调用，不自动成为Agent运行器。
