## 学习目标

区分模型、Host、Client和Server。对照具体输入解释每个参数从哪里来、返回值交给谁以及失败发生在哪一层。

## 前置知识

先按首页安装基础环境，并完成原生工具循环与相关阶段复盘。 使用环境：.venv-mcp。所有Python命令在仓库根目录运行；安装见 [运行说明](../../docs/setup.md)。

## 文件职责

- [核心文件](step_21b_order_server.py)：按本课数据流查找对应定义。
- [独立依赖](requirements.txt)：使用MCP环境安装，不混入框架环境。

## 具体输入与执行过程

```text
模型提出Tool Call
→ Host适配
→ Client发送MCP请求
→ Server执行
→ 返回结果
```

先找到入口，再标出关键函数的参数与返回点。学习脚本是分步实现；`app`中的整合版可能同时支持演示与数据库后端，观察时记下当前配置，避免混用结果。

## 运行与预期结果

**访问范围：本地演示，不请求外部模型。**

```console
python -m learning.mcp.step_21b_order_client
```

应观察到：能解释协议连接与模型工具调用的边界。



固定使用本目录锁定的MCP 2.3 API：`MCPServer`、`Client`、`StdioServerParameters`。不要直接混用早期SDK的FastMCP写法。

## 常见错误

- 导入失败：确认位于仓库根目录，并使用本课对应的独立环境。
- 运行结果与预期不同：先检查后端配置、前置服务及当前代码版本，再判断是否属于模型行为差异。
- 本例由应用中的Client负责协议通信，模型只输出工具调用意图。
