## 具体输入与执行过程

```text
SDK请求
→ 转换assistant消息
→ run_tool_loop
→ 真实MCP订单
→ SDK回答
```

先找到入口，再标出关键函数的参数与返回点。学习脚本是分步实现；`app`中的整合版可能同时支持演示与数据库后端，观察时记下当前配置，避免混用结果。

## 运行与预期结果

**访问范围：真实外部模型请求，可能收费。**

```console

```

应观察到：模型需支持工具调用；失败时停止，不自动重试。





## 常见错误

- 导入失败：确认位于仓库根目录，并使用本课对应的独立环境。
- 运行结果与预期不同：先检查后端配置、前置服务及当前代码版本，再判断是否属于模型行为差异。
- 不是；适配函数连接两种格式，模型仍使用Chat Completions。
