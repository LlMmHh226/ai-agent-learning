## 学习目标

观察模板与运行实例。对照具体输入解释每个参数从哪里来、返回值交给谁以及失败发生在哪一层。

先阅读 [准备Docker](step_01_install_start.md)。 使用环境：Docker Engine。所有Python命令在仓库根目录运行；安装见 [运行说明](../../docs/setup.md)。

## 具体输入与执行过程

```text
拉取hello-world镜像
→ 创建容器
→ 打印
→ 退出
```

先找到入口，再标出关键函数的参数与返回点。学习脚本是分步实现；`app`中的整合版可能同时支持演示与数据库后端，观察时记下当前配置，避免混用结果。

## 运行与预期结果

**访问范围：首次下载镜像需要联网；不请求模型。**

```console
docker run --rm --name learn-hello-1 hello-world
```

应观察到：Exited(0)是示例正常结束。





## 常见错误

- 导入失败：确认位于仓库根目录，并使用本课对应的独立环境。
- 运行结果与预期不同：先检查后端配置、前置服务及当前代码版本，再判断是否属于模型行为差异。
- 镜像是创建运行实例的模板，容器是有独立运行状态的实例。
