## 具体输入与执行过程

```text
ORDER_STORAGE_BACKEND=postgres
→ repository
→ psycopg
→ 原工具循环
```

先找到入口，再标出关键函数的参数与返回点。学习脚本是分步实现；`app`中的整合版可能同时支持演示与数据库后端，观察时记下当前配置，避免混用结果。

## 运行与预期结果

**访问范围：访问自己启动的教学数据库；不请求模型（正式聊天请求除外）。**

```console
python -m uvicorn main:app --reload
```

应观察到：无需改HTTP字段；同步工具在工作线程执行。



数据库与Python查询已验证后，在根.env设置 `ORDER_STORAGE_BACKEND=postgres` 并重启服务。入门默认demo，数据库故障不会静默退回demo。

## 常见错误

- 导入失败：确认位于仓库根目录，并使用本课对应的独立环境。
- 运行结果与预期不同：先检查后端配置、前置服务及当前代码版本，再判断是否属于模型行为差异。
- 不会；显式报告服务失败，防止把演示数据冒充数据库真实结果。
