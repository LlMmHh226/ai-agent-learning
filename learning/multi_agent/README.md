# 多 Agent：角色、交接与受控路由

先完成 [20I 工具循环](../frameworks/step_20i_tool_loop_graph.md)，使用 [框架环境](../../docs/setup.md)。这组示例用公开样例和固定决策复现状态流，默认无需 `.env`、真实模型或数据库。

| 课次 | 本课验收 | 讲义 |
| --- | --- | --- |
| 23A | 说清工具与角色的职责，画出订单到售后的最小交接 | [角色分工与任务交接](step_23a_roles_and_handoff.md) |
| 23B | 用不同消息和工具名单限制一个角色 | [订单 Agent](step_23b_order_agent.md) |
| 23C | 实际运行两个局部工具循环；在核实订单后进入售后 | [两个 Agent 的状态交接](step_23c_two_agents.md) |
| 23D | 校验入口候选路由，缺订单号时先澄清 | [一次路由](step_23d_router.md) |
| 23D 延伸 | 按任务依赖选择下一步，补充事实后续办原任务 | [受控主管与跨轮待办](step_23d_supervisor_demo.md) |

23C 的顺序由边和条件明确指定；23D 演示入口路由；延伸课在每一步检查就绪动作，并用业务状态续办。示例运行期间只读取虚构订单和教学规则，不会提交退货、修改订单或退款。
